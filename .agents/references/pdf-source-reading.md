# Reading source PDFs

For a PDF in `docs/sources/`, extract searchable text first with the repository's
available PDF-to-text or PDF-to-Markdown tool, then read the extracted text. Check
whether the extraction is complete before relying on it. If no suitable converter is
available, use the available text extraction tools and state any limitations.

Inspect the original PDF or rendered pages when the source is scanned, extraction is
incomplete, or layout carries meaning. This includes figures, equations, maps, complex
tables, slides, and formatting questions. Use visual inspection to resolve those
details; do not reconstruct unreadable text from context. For scanned pages that need
OCR, use an authorized OCR source or report the gap.

Prefer the manuscript source over its compiled PDF when reviewing a project article
and the `.tex` files are available. For external papers, distinguish what the text
extraction supports from what requires visual inspection.
