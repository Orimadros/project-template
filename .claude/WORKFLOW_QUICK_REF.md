# Workflow quick reference

Read `AGENTS.md` for the standing rules and `README.md` for paths and commands.
For tracked work: `open-issue` → `to-spec` or `grill-to-spec` → `implement` →
`code-review` → `ship` with a named subset → `close-issue`. Use `sitrep` for
issue progress and recent logs. Small exact edits and exploration can proceed
without an issue or spec. Each skill's `SKILL.md` has its own completion checks.
