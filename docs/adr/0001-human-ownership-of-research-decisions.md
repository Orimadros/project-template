# The researcher owns research and logic decisions

Leo retains authority over every research and logic decision. Agents identify
unresolved choices, explain alternatives, teach when asked, and implement choices
he has settled. This deliberately limits agent autonomy so implementation speed
does not leave the researcher unaware of or unaccountable for his own methods.

Agents have discretion in translating settled choices into code under prewritten
coding standards, provided that discretion changes neither meaning nor behavior.
A newly discovered substantive choice returns to Leo before dependent work proceeds.

Teaching is requested by Leo. At specification approval or a new substantive
choice, agents briefly offer to discuss methods he reasonably might not understand.
Routine operations such as calculating a correlation do not need that nudge.
Agents never test his competence as a condition of execution or withhold execution
because he has not demonstrated understanding.
