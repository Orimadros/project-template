## Core Slide-Writing Principles

- Direct source claim: The introduction and overall seminar structure should be treated as an effort to persuade a skeptical referee. The source then organizes the paper/seminar around the questions such a referee would ask. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: A research talk should be organized around skeptical audience objections, not around the author's chronology of discovery.

- Direct source claim: The speaker should be able to state the question in only a few sentences; if not, the question probably has not been sharpened enough. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: The opening research-question slide should be short, explicit, and operational. In an empirical economics talk, it should usually name the outcome, treatment/exposure/setting, and population or period.

- Direct source claim: The motivation should explain why the audience should care, using stakes such as a quantitatively important real-world problem, policy relevance, demonstrated literature interest, or gaps in existing work. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: Motivation slides should make importance concrete. A generic "this is important" opening is weaker than a measured magnitude, policy decision, literature puzzle, or missing empirical fact.

- Direct source claim: The novelty claim should be concise, and it can help to name a small set of closely related papers while saying how the present contribution differs. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: Related-work material in a seminar should be selective and contrastive. The point is not a literature review; it is to locate the contribution against the nearest substitutes.

- Direct source claim: The speaker should explain why the audience should believe the argument by briefly describing the empirical or theoretical exercises and the main conclusions. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: A talk needs an early credibility preview: data, design, model, experiment, or identifying variation should appear before the audience is asked to process many results.

- Direct source claim: The speaker should say how convinced the audience should be, while acknowledging unresolved problems such as data limits or future work. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: A serious seminar does not hide caveats. It frames them as calibration: what the talk has established, what remains uncertain, and why the remaining uncertainty does not erase the contribution.

- Direct source claim: The bottom line is whether the work changes the audience's view of the world; the speaker must have an answer. [PDF, p. 1](https://www.columbia.edu/~drd28/SuccessfulPaperSeminar.pdf)
  Interpretation: The conclusion should not merely summarize. It should state the audience's updated belief after seeing the evidence.

## Beamer-Specific Implications

- Use the source's skeptical-referee questions as a planning checklist for the first part of an economics Beamer deck: question, why care, what is new, why believe, how convinced, and what view should change.

- Keep the first substantive frame focused on the research question. A useful Beamer pattern is a claim-title frame with one short question statement and, if needed, one line for setting or estimand.

- Build the motivation frame around a concrete stake, policy margin, literature puzzle, or missing fact. Avoid spending early slides on broad background that does not answer "why care."

- Replace comprehensive related-work slides with a nearest-neighbor contribution frame: two to four close papers or literatures, each paired with the specific distinction. Citations should remain visually secondary, using the existing `\smallcitation{...}` pattern when they sit at the end of bullets.

- Add a compact credibility-preview frame before detailed results. For empirical talks, this can pair the data/design with the headline conclusion; for theory talks, it can pair the model object or experiment with the main result.

- Include a calibration moment for full seminars: a limitations, threats, or "how convinced should we be?" frame near the end, with deeper robustness and unresolved issues linked to backup slides where appropriate.

- Make the final frame answer "what changed?" with one to three belief-updating takeaways, rather than a generic recap or thank-you slide.

## What This Would Change In Our Current Framework

- Add a seminar-opening checklist to `.claude/rules/slide-writing-principles.md`: before detailed evidence, the deck should answer question, care, novelty, credibility, conviction, and belief change.

- Add a contribution-frame pattern to the citations guidance: use a small set of closest papers/literatures and state the difference, rather than showing a dense bibliography slide.

- Add an audit question for the conclusion: "Does the final substantive slide say how the audience's view should change?"

- For full research seminars, consider adding a planned calibration frame before the conclusion, especially when identification, data coverage, external validity, or mechanism interpretation is contested.

## Tensions Or Caveats

- The source is a one-page paper/seminar handout, not a slide-design manual. It supports talk-structure choices, but it does not provide guidance on typography, figures, overlays, color, or Beamer mechanics.

- The skeptical-referee frame fits economics seminars well, but it can make a short conference talk feel overly defensive if every question is turned into an explicit slide. For short talks, the checklist may be better used during planning than as visible slide titles.

- The advice to identify close papers is useful, but it can encourage citation-heavy openings. In the current framework, citations should still support the claim without competing for attention.

- The source's emphasis on concision is consistent with the current framework, but it does not by itself decide how much institutional background or identification detail a particular audience needs.
